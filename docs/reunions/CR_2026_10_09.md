## Points abordés
1. **Boîtes à moustaches :** elles doivent être developpées mieux expliquées
   - Lecture des quartiles : chaque segment contient 25 % des données
   - Différence entre les moustaches (bornes « high/low ») et le min/max réel
   - Ce que représente chaque point isolé (valeur aberrante)
   - Elles doivent aussi être déclinées par type de ventilation (AC / NV / MM)
2. **Qualité statistique des données :**
   - Représenter les distributions de Tg et Tr et les comparer à une loi normale (courbe de Gauss, 99,7 % des valeurs à ± 3σ, le reste étant des valeurs extrêmes)
   - Ajuster une loi de Weibull pour les distributions asymétriques (vitesse d'air notamment)
   - Variables à contrôler : Ta, Tg, rh, Vel, met, clo
3. **Température radiante :** créer une colonne finale Tg/Tr, avec une conversion Tg → Tr selon pythermalcomfort (ISO 7726 ou ASHRAE verif) qui tient compte de la taille du globe
4. **Vitesse d'air :**
   - Récapituler les colonnes disponibles (Vel, Vel_h, Vel_m, Vel_l)
   - Construire Vel_final : moyenne des trois hauteurs si elles existent, sinon la mesure ponctuelle
5. **SET :**
   - Recalculer le SET avec pythermalcomfort, en vérifiant la norme utilisée par la librairie (ISO ou ASHRAE)
   - Refaire ce calcul pour les bâtiments AC, NV et MM
6. **Type de ventilation :**
   - Chaque vote est rattaché à un type de ventilation
   - Analyses en trois paniers AC / NV / MM
   - Préciser systématiquement « clim ou pas clim »
   - Rapprochement MM ≈ NV évoqué pour la vitesse d'air, Tg/Tr et l'humidité (voir Décisions)
7. **Analyse par nombre de votes :**
   - par type de ventilation ;
   - par nombre et type de bâtiment ;
   - distribution des vitesses ;
   - paramètres individuels (clo, met) vs paramètres d'environnement (Tr, HR, vitesse d'air…)
8. **Diagramme de Sankey :** relier études, type de bâtiment, ventilation et paramètres disponibles, pour comparer les jeux de données

## Décisions
- Seuls les votes pour lesquels une vitesse d'air (Vel) est renseignée dans la base sont conservés
- Le type de bâtiment est toujours mentionné dans les résultats
- Les analyses sont subdivisées selon cooling_type (AC / NV / MM). **À trancher :** garder MM séparé ou le regrouper avec NV (SANKEY permet de visualiser les proportions)
- Vel_final = moyenne des 3 hauteurs, sinon mesure ponctuelle
- Tr et SET sont recalculés (ISO 7726 / ASHRAE, pythermalcomfort) plutôt que repris tels quels de la base
