## Points abordés
1. **Problème identifié :** incohérences entre les articles et la base de données sur le sous-ensemble 100 % tropical (≈ 29 000 votes, 19 études publiées).
2. **Comparaison papier vs base :** étendre l'analyse comparative à l'ensemble des 19 études, classées dans un tableau unique (liste totale des études vs base).
3. **Statistiques descriptives :** min / max / mean / std pour chaque variable, papier vs base, avec un group by par étude, pour évaluer la complétude des données.
4. **Vitesse d'air :** distribution par étude, classée en niveaux (haut / milieu / bas) selon la vitesse moyenne.
5. **Visualisations :**
   - boîtes à moustaches par variable, avec SET et SET à v = 0 ;
   - nuages de points par variable pour repérer les valeurs aberrantes (ex. clo entre 1,52 et 2,32) ;
   - proportion du nombre de votes par étude et nombre de votes par sujet.
6. **Cartographie des études tropicales :** carte du monde avec, pour chaque étude, le type de bâtiment (bureau / logement, en couleur), le type de ventilation (AC / NV / MM), le niveau de vitesse d'air, le nombre d'études et le nombre de votes. Classement possible par classe climatique et par année d'étude.
7. **Ouverture vers la question 2 :** identifier les autres études, tous climats confondus, avec une vitesse d'air > 0,13 / > 0,2 / > 0,5 m/s, selon le type de ventilation (AC / NV / MM).
8. **Fiche par étude :** fonction qui renvoie, pour une étude donnée, ses résultats : votes, sujets (% H/F), climat, coordonnées, etc.
